# 🌱 EcoCalc 2026 - Калькулятор экологического следа

![EcoCalc Preview](https://via.placeholder.com/800x400/2E8B57/FFFFFF?text=EcoCalc+2026)

Интерактивный веб-приложение для расчета и визуализации вашего углеродного следа. Проект создан с использованием современных веб-технологий и демонстрирует передовые практики разработки.

## ✨ Особенности

- **📊 Интерактивный расчет** - 4 категории экологического воздействия
- **🎨 Современный дизайн** - адаптивный интерфейс с анимациями
- **📈 Визуализация данных** - графики, диаграммы, прогресс-бары
- **🌙 Темная тема** - поддержка светлой и темной тем
- **📱 Адаптивность** - отлично работает на всех устройствах
- **💾 Локальное сохранение** - сохраняйте свои планы улучшений

## 🛠 Технологии

- **HTML5** - семантическая разметка
- **CSS3** - Grid, Flexbox, CSS Variables, анимации
- **Vanilla JavaScript** - ES6+ модули, Fetch API, LocalStorage
- **Chart.js** - библиотека для визуализации данных
- **SVG** - векторная графика и анимации
